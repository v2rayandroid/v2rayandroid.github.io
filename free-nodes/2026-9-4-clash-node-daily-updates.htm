第一章：认识小火箭 Shadowrocket

1.1 什么是小火箭？

小火箭 Shadowrocket 是一款专为 iOS 设备设计的网络代理客户端，支持 Shadowsocks、Vmess、Trojan 等多种主流代理协议。它不仅能帮助你访问被限制的网站和服务，还能有效保护你的网络隐私，防止数据被窃取或监控。

1.2 小火箭的核心优势

  • 用户友好：界面简洁直观，新手也能快速上手。
  • 多协议支持：兼容 Shadowsocks、Vmess、Trojan 等多种协议，适应不同网络环境。
  • 灵活配置：支持自定义 DNS、规则设置和代理策略，满足个性化需求。
  • 隐私保护：通过加密传输数据，防止 ISP 或第三方监控你的网络活动。

第二章：下载与安装

2.1 官方渠道获取

小火箭 Shadowrocket 在 App Store 中提供下载，但由于某些地区的限制，可能需要切换 Apple ID 地区或通过其他方式获取。

步骤：
1. 打开 App Store，切换至支持 Shadowrocket 的地区（如美区、港区）。
2. 搜索 "Shadowrocket" 并购买（通常售价 $2.99）。
3. 下载并安装。

2.2 替代下载方式

如果无法通过 App Store 获取，可尝试以下方法：
- 通过第三方签名工具（如 AltStore）安装 IPA 文件。

⚠️ 注意：非官方渠道可能存在安全风险，建议优先选择正版。

第三章：基础配置教程

3.1 添加服务器

  1. 打开 Shadowrocket，点击右上角 + 按钮。
  2. 选择代理类型（如 Shadowsocks、Vmess）。
  3. 填写服务器信息（地址、端口、密码、加密方式等）。
  4. 保存并返回主界面。

3.2 连接与断开

  • 连接：点击服务器名称，再点击底部 连接 按钮。
  • 断开：再次点击 连接 按钮即可。

3.3 检查连接状态

  • 成功连接后，状态栏会显示 VPN 图标。
  • 可在 Shadowrocket 主界面查看实时流量和连接时长。

第四章：高级功能与优化

4.1 自定义 DNS

优化 DNS 可以提升解析速度并避免污染：
1. 进入 设置 → DNS。
2. 添加公共 DNS（如 1.1.1.1、8.8.8.8）。
3. 启用 DNS over HTTPS (DoH) 增强隐私。

4.2 规则配置

通过规则可以实现智能分流（如国内直连、国外走代理）：
1. 进入 配置 → 规则。
2. 添加规则集（如 GFWList、自定义规则）。
3. 设置匹配策略（DIRECT、PROXY、REJECT）。

4.3 日志与调试

如果遇到连接问题，可查看日志排查：
1. 进入 日志 选项卡。
2. 检查错误信息（如超时、认证失败）。
3. 根据日志调整服务器或网络设置。

第五章：常见问题与解决方案

5.1 连接失败怎么办？

  • 检查服务器信息：确保地址、端口、密码正确。
  • 更换协议：尝试 Shadowsocks 或 Vmess 不同加密方式。
  • 网络环境：某些 WiFi 可能屏蔽代理，可切换 4G/5G 测试。

5.2 如何提升速度？

  • 选择低延迟的服务器。
  • 启用 UDP 转发（若支持）。
  • 关闭不必要的规则以减少性能开销。

5.3 是否支持多设备？

Shadowrocket 仅限 iOS 设备，但可通过订阅方式同步服务器配置到其他客户端（如 Clash、Surge）。

第六章：安全与隐私建议

  1. 定期更换密码：避免长期使用同一组认证信息。
  2. 启用 TLS 加密：Vmess 协议建议搭配 TLS 以增强安全性。
  3. 避免公共 WiFi：即使使用代理，公共网络仍可能存在风险。

FAQ

Trojan 的伪装域名有什么要求？
Trojan 的伪装域名必须是可以通过 HTTPS 正常访问的真实网站，并且 SSL 证书有效。伪装域名用于与服务器证书匹配，使得流量在外观上完全与正常 HTTPS 请求一致。
Quantumult X 可以用脚本自动切换节点吗？
可以。Quantumult X 支持通过脚本逻辑判断网络延迟或连接失败情况，并自动切换节点。用户可以编写自定义 JS 规则，从而实现智能代理与按需分流，适合高级用户使用。
VLESS + XTLS 模式在移动网络下表现如何？
XTLS 降低加密开销，减少握手次数，适合高延迟或不稳定的移动网络。结合策略组和多出口节点，可提升访问速度和连接稳定性，确保用户体验流畅。
Mellow 的 TUN 模式适合哪些应用？
TUN 模式拦截系统 IP 层流量，可实现全局代理。适合游戏、视频、浏览器和其他全局应用，实现低延迟和稳定连接，保证所有流量通过代理节点，提高访问速度和稳定性。
Sing-box 如何实现精确域名分流？
Sing-box 可以按域名设置分流规则，将不同流量发送到指定节点。结合策略组使用，可实现网页、视频和游戏流量精准分配，提高访问速度和网络稳定性。
VMess AEAD 加密如何确保数据传输安全？
AEAD 加密可防止数据篡改、重放攻击和流量特征泄露。在高封锁环境中保证节点可用，提升数据安全和连接稳定性，降低被检测风险，确保长期安全访问体验。
Trojan 使用自签名证书会带来哪些问题？
自签名证书无法被客户端默认信任，可能导致连接失败或需要手动安装证书。它也容易被中间人伪造识别，不利于长期生产环境安全部署，建议使用可信 CA 证书以获得更好兼容性与安全性。
VLESS + XTLS 如何在高延迟网络中优化连接？
XTLS 模式通过减少握手和加密开销降低延迟。结合策略组和多节点切换，可在高延迟或不稳定网络环境下保证网页浏览、视频播放和游戏连接稳定，提高整体体验。
Clash 订阅被墙或无法下载如何绕过？
若订阅源被直接屏蔽，可尝试先在境外服务器上用代理代理获取订阅并通过中转服务器公开一个新的链接；或者使用 HTTPS 与 CDN 中转、或将订阅以文件形式托管在不易被封的云存储上。
Hiddify Next 的 Web 面板有什么用途？
Hiddify Next 自带 Web 管理面板，管理员可通过浏览器管理用户、监控流量、生成订阅链接并部署节点。无需命令行操作，极大提高管理效率。
